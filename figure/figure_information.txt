FIGURE 1 – CLASS DISTRIBUTION IN CICIoT2023 TRAINING DATASET

The graph shows that the dataset is highly imbalanced. The DDoS class contains the largest number of samples, while BruteForce and Web-based attacks contain considerably fewer samples. This imbalance is important because a model may become biased toward classes having a larger number of training examples.

Purpose:
To visualize the original class distribution and identify the imbalance present in the dataset.

CONFUSION MATRIX FIGURES


FIGURE 6 – CONFUSION MATRIX: DNN

This confusion matrix presents the classification results of the baseline DNN across the eight attack classes.

Rows represent the true classes, while columns represent the predicted classes. Diagonal values represent correctly classified samples, whereas off-diagonal values represent misclassifications.

The DNN performs particularly well on the DDoS, DoS, and Mirai classes. Some confusion can be observed between related traffic categories such as DDoS and DoS, as well as between Benign, Recon, Spoofing, and Web-based traffic.

Purpose:
To examine class-wise classification performance and identify specific misclassification patterns.


FIGURE 7 – CONFUSION MATRIX: DNN + DROPOUT

This figure shows the confusion matrix obtained using the DNN model with Dropout regularization.

The diagonal values indicate correctly classified samples. Compared with the baseline DNN, Dropout modifies the distribution of errors across several classes. The model maintains strong classification performance for DDoS, DoS, and Mirai traffic.

Purpose:
To evaluate the effect of Dropout regularization on class-wise classification performance.


FIGURE 8 – CONFUSION MATRIX: DNN + L2

This confusion matrix represents the predictions produced by the DNN model using L2 regularization.

The model correctly identifies a large proportion of DDoS, DoS, and Mirai samples. However, some misclassification remains between DDoS and DoS and among the lower-frequency attack classes.

Purpose:
To examine how L2 weight regularization affects classification behaviour.


FIGURE 9 – CONFUSION MATRIX: PROPOSED DNN

This figure presents the confusion matrix for the proposed DNN architecture incorporating additional regularization and stabilization techniques.

The matrix shows strong diagonal values for the major classes, particularly DDoS, DoS, and Mirai. Misclassifications are more visible for classes such as Recon, Spoofing, and Web-based attacks.

Purpose:
To evaluate the class-wise performance of the proposed DNN architecture.


FIGURE 10 – CONFUSION MATRIX: 1D CNN

This figure presents the classification results obtained using the 1D CNN model.

The 1D CNN achieves the highest overall accuracy among the evaluated models. Strong diagonal values can be observed for DDoS, DoS, and Mirai. The model is also able to classify several other traffic categories effectively.

Purpose:
To analyze the class-level performance of the best-performing model in the experiment.


FIGURE 11 – CONFUSION MATRIX: LSTM

This figure shows the confusion matrix generated by the LSTM model.

Compared with the DNN and 1D CNN models, the LSTM produces considerably more confusion between several classes. In particular, substantial misclassification can be observed between DDoS and DoS, and among Benign, BruteForce, Recon, and Spoofing classes.

Purpose:
To examine the limitations of sequential recurrent modelling for the given tabular network-flow representation.

FIGURE 13 – MACRO F1 SCORE COMPARISON

This figure compares the Macro F1 score of the seven evaluated models.

The Macro F1 score gives equal importance to each class and is therefore particularly useful for evaluating classification performance on an imbalanced dataset.

The 1D CNN achieves the highest Macro F1 score at approximately 0.638, followed by the DNN at approximately 0.635. The LSTM records the lowest Macro F1 score at approximately 0.434.

Purpose:
To compare balanced class-wise performance across all models.


FIGURE 14 – TRAINING TIME COMPARISON

This figure compares the time required to train each deep learning architecture.

The DNN-based models require considerably less training time than the sequence-based and attention-based models. The Transformer requires the highest training time, approximately 890 seconds, while the 1D CNN requires approximately 306 seconds and the LSTM approximately 241 seconds.

The baseline DNN requires only a small fraction of the time required by the Transformer while achieving competitive classification accuracy.

Purpose:
To evaluate the computational efficiency of the different architectures in addition to their predictive performance.


OVERALL INTERPRETATION

The figures collectively demonstrate that model complexity does not necessarily result in better performance for the given CICIoT2023 tabular network-flow classification problem.

The 1D CNN provides the best overall predictive performance, achieving approximately 75.74% accuracy and the highest Macro F1 score among the evaluated models. The baseline DNN provides a strong balance between performance and computational cost, achieving 75.30% accuracy with substantially lower training time.

The LSTM and Transformer models perform worse than the simpler architectures in this experiment. This suggests that treating the available network-flow features as sequential data or attention tokens does not necessarily provide an advantage when compared with models better suited to the structure of the given tabular representation.

The confusion matrices further show that classification errors are not uniformly distributed. The models generally identify high-frequency classes such as DDoS, DoS, and Mirai more effectively, while relatively smaller or more overlapping classes show greater confusion.

Therefore, the figures support the conclusion that architecture selection should consider both the nature of the input data and computational efficiency rather than relying only on architectural complexity.
