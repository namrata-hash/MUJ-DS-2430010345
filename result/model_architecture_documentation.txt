1. EXPERIMENT OVERVIEW
----------------------
The final experiment compares seven deep learning architectures using the same
eight-class CICIoT2023-based experimental setup.

Input:
- 39 numerical network-flow features

Output:
- 8-class softmax classification

Common training configuration:
- Optimizer: Adam
- Loss: Sparse Categorical Crossentropy
- Batch size: 256
- Maximum epochs: 20
- Validation: stratified 20% validation split
- Scaled input: StandardScaler
- Test evaluation: original held-out test distribution

Models:
1. DNN
2. DNN + Dropout
3. DNN + L2 Regularization
4. Proposed DNN
5. 1D CNN
6. LSTM
7. Transformer Encoder


2. DNN BASELINE
---------------
Purpose:
Baseline fully connected neural network for tabular network-flow features.

Architecture:
Input (39)
  -> Dense(128, ReLU)
  -> Dense(64, ReLU)
  -> Dense(32, ReLU)
  -> Dense(8, Softmax)

Training:
- Adam
- Sparse categorical crossentropy
- Batch size 256
- 20 epochs


3. DNN + DROPOUT
----------------
Purpose:
Ablation model used to examine the effect of Dropout regularization.

Architecture:
Input (39)
  -> Dense(128, ReLU)
  -> Dropout(0.30)
  -> Dense(64, ReLU)
  -> Dropout(0.30)
  -> Dense(32, ReLU)
  -> Dense(8, Softmax)

Training:
- Adam
- Sparse categorical crossentropy
- Batch size 256
- 20 epochs


4. DNN + L2 REGULARIZATION
--------------------------
Purpose:
Ablation model used to examine the effect of L2 weight regularization.

Architecture:
Input (39)
  -> Dense(128, ReLU, L2=0.001)
  -> Dense(64, ReLU, L2=0.001)
  -> Dense(32, ReLU)
  -> Dense(8, Softmax)

Training:
- Adam
- Sparse categorical crossentropy
- Batch size 256
- 20 epochs


5. PROPOSED DNN
---------------
Purpose:
Combined regularization model using L2, Batch Normalization and Dropout.

Architecture:
Input (39)
  -> Dense(128, ReLU, L2=0.001)
  -> Batch Normalization
  -> Dropout(0.30)
  -> Dense(64, ReLU, L2=0.001)
  -> Dropout(0.30)
  -> Dense(32, ReLU)
  -> Dropout(0.20)
  -> Dense(8, Softmax)

Training:
- Adam
- Sparse categorical crossentropy
- Batch size 256
- Maximum 20 epochs
- EarlyStopping:
    monitor = val_loss
    patience = 4
    restore_best_weights = True
- ReduceLROnPlateau:
    monitor = val_loss
    factor = 0.5
    patience = 2
    min_lr = 1e-6


6. 1D CNN
---------
Purpose:
Convolutional model that processes the 39 features as an ordered
one-dimensional representation.

Input reshaping:
(39,) -> (39, 1)

Architecture:
Input (39, 1)
  -> Conv1D(filters=64, kernel_size=3, ReLU)
  -> Batch Normalization
  -> MaxPooling1D(pool_size=2)
  -> Conv1D(filters=128, kernel_size=3, ReLU)
  -> MaxPooling1D(pool_size=2)
  -> Flatten
  -> Dense(128, ReLU)
  -> Dropout(0.30)
  -> Dense(8, Softmax)

Training:
- Adam
- Sparse categorical crossentropy
- Batch size 256
- Maximum 20 epochs
- EarlyStopping / ReduceLROnPlateau callbacks


7. LSTM
--------
Purpose:
Recurrent architecture used to test whether sequential processing of the
feature representation improves intrusion classification.

Input reshaping:
(39,) -> (39, 1)

Architecture:
Input (39, 1)
  -> LSTM(64, return_sequences=True)
  -> Dropout(0.30)
  -> LSTM(32)
  -> Dropout(0.30)
  -> Dense(64, ReLU)
  -> Dense(8, Softmax)

Training:
- Adam
- Sparse categorical crossentropy
- Batch size 256
- Maximum 20 epochs
- EarlyStopping / ReduceLROnPlateau callbacks


8. TRANSFORMER ENCODER
----------------------
Purpose:
A lightweight attention-based architecture added in the later project stage.

Representation:
Each of the 39 numerical input features is treated as one token.

Input:
(39, 1)

Feature/position embedding:
- Dense projection from each scalar feature to d_model=64
- Trainable positional embedding
- Projected feature representation + positional embedding

Transformer encoder configuration:
- d_model = 64
- Number of attention heads = 4
- Feed-forward dimension = 128
- Encoder blocks = 2
- Attention/encoder dropout = 0.20
- GELU activation in the feed-forward network
- Layer normalization
- Residual connections

Architecture:
Input (39, 1)
  -> Feature + Positional Embedding (d_model=64)
  -> Transformer Encoder Block 1
       Multi-Head Self-Attention
       Dropout(0.20)
       Residual + LayerNorm
       Feed-Forward Dense(128, GELU)
       Dropout
       Dense(64)
       Dropout
       Residual + LayerNorm
  -> Transformer Encoder Block 2
       same configuration
  -> GlobalAveragePooling1D
  -> Dense(64, ReLU)
  -> Dropout(0.30)
  -> Dense(8, Softmax)

Training:
- Adam
- Sparse categorical crossentropy
- Batch size 256
- Maximum 20 epochs
- EarlyStopping / ReduceLROnPlateau callbacks


9. ARCHITECTURE COMPARISON SUMMARY
-----------------------------------
Model              Main idea
---------------------------------------------------------------
DNN                Fully connected nonlinear feature learning
DNN + Dropout      DNN with stochastic regularization
DNN + L2           DNN with weight regularization
Proposed DNN       L2 + BatchNorm + Dropout
1D CNN             Local feature-pattern extraction
LSTM               Recurrent/sequential feature processing
Transformer        Self-attention across feature tokens


10. FINAL PERFORMANCE SUMMARY
-----------------------------
Best accuracy:
- 1D CNN: 75.74%

Best F1:
- 1D CNN: 63.77%

Lowest training time:
- DNN + L2: 27.66 seconds

Highest training time:
- Transformer: 889.91 seconds

Efficiency-oriented baseline:
- DNN: 75.30% accuracy in 32.37 seconds

The final results show that greater architectural complexity did not
automatically produce better classification performance under this
experimental representation.
